# Tap – универсальный парсер аргументов командной строки

**Tap** — это набор лёгких библиотек для создания CLI-приложений на **Go** и **Rust**.  
Обе реализации следуют единой концепции: минимум кода, максимум удобства.

---

## Общие возможности

- Команды с обязательными и опциональными аргументами
- Флаги `--flag`, `--key=value`, `--key:value`
- Встроенные цветовые коды (`[?GN]`, `[?RD]`, `[?RT]`, `[?BOLD]`, `[?BACK...]`)
- Автоматическая генерация справки с группировкой алиасов
- Поддержка субкоманд (вложенных парсеров)
- Возможность отключения цветов глобально
